# 기준 그림 자리 (지금은 비어 있음)

여기에는 **사용자가 "이것이 우리 그림체다"라고 고른 그림**만 둡니다.
검토자는 기준표(`../rubric.md`)와 이 폴더의 그림만 보고 "우리 그림체와 어울리는지"를 채점합니다.

- 넣는 사람: 사용자. 에이전트가 그림을 골라 넣거나 만들어 넣지 않습니다.
- 파일 형식: png, jpg, jpeg, webp. 이 폴더 바로 아래에 둡니다(하위 폴더는 읽지 않습니다).
- 이 README 는 검토자에게 전달되지 않습니다. 그림 파일만 전달됩니다.
- 그림이 한 장도 없으면 `tools/art_loop.sh pack`·`record` 가 "NOT READY" 로 멈춥니다.
- 기준 그림을 바꾸면 그 전 회차 점수와는 바로 비교할 수 없습니다. 바꾼 날짜와 까닭을 `notes/art-loop.md` 에 적습니다.
