# 15. 위험 요소 및 미결정 사항

## 1. 주요 위험

| 위험 | 영향 | 완화 |
|---|---|---|
| 기능 범위 과대 | 개발 지연/품질 저하 | vertical slice, MVP 제한 |
| NPC 수 증가 | 서버 AI 부하 | 계층형 시뮬레이션, 중앙 스케줄러 |
| 대규모 월드 | 메모리/렌더링/내비게이션 부하 | 구역 스트리밍, 프로파일링 |
| 멀티플레이 동기화 | 상태 불일치/치트 | 서버 권한, RPC 검증 |
| 동적 건축 | navmesh 갱신 비용 | 구역/타일 단위 갱신 실험 |
| 복잡한 관계 AI | 예측 불가/테스트 어려움 | 이벤트 기록, 결정론 seed, 디버그 도구 |
| 저장 데이터 복잡성 | 세이브 손상/마이그레이션 | 스키마 버전, 백업, 원자적 저장 |
| 시뮬레이션 오프라인 진행 | 플레이어 부재 중 과도한 손실 | 서버 옵션 및 계산 상한 |
| 비밀 정보 멀티플레이 | 클라이언트 정보 누출 | 플레이어별 knowledge projection |
| AI 행동의 부적절한 묘사 | 편향/낙인 | 정신적 고통과 폭력 원인을 단순 연결하지 않음 |

## 2. 미결정 질문

아래 항목은 후속 기획에서 결정해야 한다. Claude Code는 개발을 막지 않는 임시 가정을 명시하고, 임의로 제품 정책을 확정하지 않는다.

### 제품/플레이
- 최종 최대 동시 플레이어 수는 몇 명인가?
- 공개 서버와 개인 서버 중 어떤 것을 우선 제공할 것인가?
- 플레이어 사망 후 같은 캐릭터로 복귀 가능한가?
- 캐릭터 사망/좀비화 여부는 서버별로 조절할 것인가?
- PvP 및 플레이어 절도는 허용할 것인가?

### 월드
- 4km × 4km 후보 크기가 적절한가?
- 월드가 절차 생성인가, 수작업 맵인가, 혼합인가?
- 서버가 비어 있어도 작물/부패/감염이 진행되는가?
- 지역별 자원 재생성은 있는가?

### NPC/사회
- 서버당 NPC 최대 수는 얼마인가?
- NPC 수용/영입 제한은 쉘터 크기/식량/침대와 연동하는가?
- 연애는 독점 관계를 기본으로 할 것인가?
- NPC의 성인 관계/가족/출산 콘텐츠는 어디까지 포함할 것인가?
- 배신/살인 같은 중대 행동의 빈도와 금지 조건은 무엇인가?
- NPC 개인 비밀을 다른 플레이어에게 얼마나 공개할 것인가?

### 세계관/동물
- 감염 가능한 동물의 최종 종 목록은 무엇인가?
- 동물 감염은 물림만 가능한가, 혈액/체액도 가능한가?
- 치료제는 감염 후 어느 단계까지 효과가 있는가?

### 운영/배포
- 계정/친구 초대/서버 브라우저가 필요한가?
- 모드와 사용자 제작 콘텐츠를 지원할 것인가?
- 서버 관리 명령/백업/관리자 도구는 어떤 범위인가?

## 3. 미결정 항목 처리 규칙

- 구현이 가능한 경우 설정값/인터페이스만 먼저 만든다.
- 제품 정책과 밸런스를 하드코딩하지 않는다.
- 추후 변경 비용이 큰 항목은 ADR로 결정한다.
- 가정으로 진행한 경우 코드 주석과 문서에 `PROVISIONAL`을 표시한다.
