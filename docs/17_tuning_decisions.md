# 17. 수치·규칙 조정 결정표

## 이 문서는

지금까지 구현하면서 "일단 이렇게 해 두고 나중에 정하자"(PROVISIONAL)로 남긴 수치와 규칙 가운데, **문서가 사용자 결정이 필요하다고 표시한 것**만 한곳에 모았다. 근거는 docs/15(임시 가정 표와 "사용자 확인이 필요한 결정 모음"), docs/00 §3·§8, docs/13 §14~§15이고, 현재 값은 `data/tuning/*.tres`와 `resources/definitions/` 파일에서 직접 읽었다(2026-11-16, main `b204fea`).

사용법:

1. 맨 위 **먼저 정할 것**(★)부터 본다. 플레이 감각을 가장 크게 바꾸는 것들이다.
2. 그다음 주제별 표를 위에서 아래로 훑으며 마지막 칸 **결정**에 적는다. "그대로", 숫자, 고른 선택지, "나중에" 중 아무거나 짧게 적으면 된다.
3. 조정자가 적힌 결정을 설정 파일 변경(값만 바꾸면 되는 것)과 ADR(규칙이 바뀌는 것, docs/00 §7)로 옮긴다.

표기: 시간은 따로 적지 않으면 **실제 초**(행동 시간)다. "월드 N시간"은 게임 달력 시간이고 24배속이라 실제로는 N/24시간이다(ADR-006). 근거 ID는 docs/15의 항목 번호다.

## 문서와 설정 파일이 어긋나는 곳

현재 설정 파일이 맞고, 옛 표가 뒤에 바뀐 사정을 다 반영하지 않은 경우다. 결정에는 위 표의 "현재 값"을 쓰면 된다.

1. **새 월드 시작 아이템**: docs/15 P2-121(§11.1)은 시험용 물건·식량 2묶음·물 2묶음·파이프만 적었지만, `dev_world_seed.tres`에는 붕대 3·치료제 2·목재 20×2·못 30도 있다(§9.1·§12의 "붕대 3개, 치료제 2개"와는 맞는다).
2. **새 캐릭터 자동 시작**: docs/15 §11.4 5번은 "10초 뒤 자동 시작"이지만, 전용 서버는 `character_settings.tres` `server_requires_character_creation` true라서 플레이어가 캐릭터를 만들어야 시작한다(P2-167). 자동 시작은 테스트용 조립에만 있다.
3. **수면 시간**: P2-150 표의 "월드 8시간 = 실제 20분"은 옛 값이다. 현재 `rest_fatigue_hours_from_max` 3.2(실제 8분, P2-180).
4. **줍기 합치기**: P2-T14 결정 모음 3번의 "줍기와 달리 건네기만 합침"은 옛 규칙이다. 건네기는 ADR-021로 없어졌고 줍기가 합친다(`merge_stacks_on_pickup` true, P2-216). P2-T14 목록의 나머지(1·2·4~7번)는 기능이 없어 결정할 것이 없다.
5. **즉시 완공**: P3-4a 결정 모음 2번의 "공짜로 즉시 지음"은 P3-5에서 바뀌었다(`instant_completion` false, 청사진 → 자재 → 작업).
6. **보이지 않는 건물 벽**: P3-3 결정 모음 6번의 "벽이 보이지 않는다"는 P3-4b에서 해소됐다(P3-204).
7. **플레이어 좀비 규칙**: P2-132 표 본문은 옛 기본값("감염이 사망 원인일 때")을 설명하지만, 설정은 `player_death_zombie_rule` 2 = INFECTED_AT_DEATH로 ADR-011과 맞다.
8. **건네기 설정**: docs/15 §14.5 머리말이 가리키는 `hand_over_range_m`, `hand_over_modifier_key`, `hand_over_quantity`는 설정 파일에 더 이상 없다(ADR-021로 기능이 철회됨).
