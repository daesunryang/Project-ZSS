# camera-height 작업 메모

## 2026-11-19

- 사용자 확정 요청: "시점 높낮이도 넣어줘"
- 조정자 범위에 따라 마우스 휠 단계 줌과 PageUp/PageDown 카메라 기준 높이 조절을 클라이언트 전용으로 추가한다.
- 기본 시점은 거리 6m, 기준 높이 1.5m, 피치 -0.35rad, 높이 오프셋 0m로 유지한다.
- PROVISIONAL 수치: 줌 3~10m(1m 단계), 높이 오프셋 -1~+3m(0.5m 단계), 지면 여유 0.25m.
- PROVISIONAL 건축 프리뷰 최소 거리는 2.5m이며 기존 클라이언트 배치 사거리 4m 안에서만 고른다. 캐릭터 타일과 네 변은 계속 피한다.
- 프리뷰 보정은 요청할 격자 슬롯을 고르는 클라이언트 예상만 바꾸며 서버 규칙·수치·프로토콜은 바꾸지 않는다.
- 조정자의 1280×720 기본 카메라 확인 결과, 4m 배치 사거리 안의 땅은 캡슐 뒤에 가려져 프리뷰 거리를 더 미는 것으로 해결하지 않는다.
- 건축 모드 동안 로컬 플레이어의 캡슐과 이름표만 PROVISIONAL 알파 0.30으로 표시하고, 모드를 끄면 원래 표시로 복원한다. 다른 플레이어와 공유 재질은 바꾸지 않는다.
- 실제 창에서 휠 방향·단계, 높이 키 조작감, 기본/극단 시점의 프리뷰 가시성, HUD 높이를 다시 확인해야 한다.
