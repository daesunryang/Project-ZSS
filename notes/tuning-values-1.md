구현에서 파생한 값과 기록:

- 감염 단계 시간은 기존 `2/6/12/12/6`에 `60/38`을 곱해 `3.1578947368421053 / 9.473684210526315 / 18.94736842105263 / 18.94736842105263 / 9.473684210526315` 월드 시간으로 저장한다.
- 체력 자연 회복률은 `100 / (20분 × 60초 × 24배속)` = `0.003472222222222222/월드초`다. 기존 0.02의 정확한 0→100 시간은 실제 3.472222…분이므로 감소 비율은 `25/144`; 상처 회복률에도 같은 비율을 적용해 `0.00001736111111111111/월드초`로 한다.
- 기본 소음 모델에서 들리는 거리는 `세기 - 1m`이므로 걷기 세기 6, 달리기 세기 13, 엎드려 걷기 배율 0.5로 각각 약 5m/12m/2m를 만든다.
- Shift를 달리기에 배정하면서 기존 남에게 쓰기 보조 키는 겹치지 않는 Alt로 옮긴다.
- 달리기 스태미나 소모량은 사용자 수치가 없으므로 기존 기본 회복률과 같은 `5/실제초`를 PROVISIONAL로 둔다. 달리는 틱에는 스태미나를 회복하지 않고, 0이면 걷기로 처리하며 엎드린 상태에서는 달릴 수 없다.
- 코드 확인 결과 `tracked_target_min_visibility` 1.0은 유지되지만 추격은 거리만으로 끊기지 않는다. 대상이 전체 시야 거리 밖, 시야각 밖, 또는 벽·닫힌 문으로 가려지면 한 번의 AI 판단 뒤 SEARCH로 전환하고 기본 12초간 마지막 위치를 수색한다. NPC 코드는 이번 작업에서 바꾸지 않는다.
