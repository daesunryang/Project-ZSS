# NPC: 혼자 버티는 생존자 (계획, 2026-11-23)

## 사용자 지시 원문 (2026-11-23)

> 그렇게 고치고 npc는 랜덤 집에서 혼자 버티고 살아남는 형태, 유저가 발견했을 때 포섭을 할 지 죽일지는 유저 선택, 역으로 성격이 포악하거나 대화에서 트러블이 생길 시 유저를 공격할 수 있음
> npc는 자유의지가 있으며 생존을 최우선 시 함
> 거처를 바꿔다닐 수도 있음

"그렇게 고치고"는 앞 물음("기존 월드에도 빠진 5명이 들어가게 고칠까요?")의 답이다. 그 수정은 같은 날 따로 들어갔다(docs/15 P4-006).

## 지금과 달라지는 것

지금(F-6까지)의 NPC는 한 마을 사람처럼 산다: 세 집에 나눠 살고, 정해진 일터에 출근하고, 집에 채워 둔 식량을 먹는다. 새 지시는 이것을 바꾼다. 최신 지시가 우선이다(AGENTS.md).

| 지금 | 바뀐 뒤 |
|---|---|
| 명단의 집·침대가 정해져 있음 | 월드 시드로 고른 **빈 건물 하나에 혼자** 산다 |
| 일터 출근(`work`), 근무 시간대 | 일 대신 **수색**(보관함을 뒤져 음식·물·무기를 모음). 일은 포섭된 뒤에만(F-20) |
| 집 식량은 처음 한 번 채움 | 집 보관함의 전리품과 수색한 것으로 버팀(F-15를 흡수) |
| 체력 없음, 죽지 않음 | 다치고 죽는다(F-25를 앞당김). 죽이면 소지품을 떨어뜨림 |
| 도주만 함 | 생존이 먼저: 피하기, 숨기, 막히면 싸우기. 위험한 곳은 기억(F-16 흡수) |
| 한 집에 머묾 | **거처를 옮긴다**: 먹을 것이 떨어지거나, 집 근처에 좀비가 자주 보이거나, 플레이어에게 공격받으면 다른 빈 건물로 |
| 플레이어와 상호작용 없음 | **발견 → 대화 → 포섭 또는 적대**. 죽일지는 플레이어가 정한다 |
| — | 포악한 성격, 대화가 틀어짐 → NPC가 먼저 공격할 수 있다 |

게임 안에 LLM·외부 API는 쓰지 않는다(AGENTS.md). 대화는 **정해진 선택지**(인사, 도움 주기, 같이 가자, 거래, 위협 등)와 성격·신뢰·두려움·배고픔으로 계산한 반응이다.

## 티켓 (NPC 갈래, 순서대로)

기존 NPC 갈래 순서(F-16 → F-19 → F-20 → F-5)를 아래로 바꾼다. F-19(기분대로 일하기)는 혼자 사는 동안에는 일이 없으므로 F-20 뒤로 미루고 포섭된 NPC에만 쓴다.

| 티켓 | 내용 | 기존 티켓과의 관계 |
|---|---|---|
| F-33 | **넓은 맵과 아주 많은 집**(2026-11-23 사용자: "맵에 크기를 광활하게 해야해 집이 엄청 많아야해 프로젝트 좀보이드 처럼"): 4km × 4km 월드, 월드 시드로 만드는 마을·길·농가, 셀을 처음 불러올 때 한 번만 배치. 개발 맵 건물은 가운데 그대로. notes/f33-vast-map.md, docs/09 §15.3.1 | 새 티켓. **F-28 앞**: F-28이 고를 건물을 만든다 |
| F-28 | **혼자 사는 배치**: 월드 시드로 NPC마다 빈 건물 하나를 골라 그 안에 놓는다(한 건물에 한 명). 일터·근무 시간대를 쓰지 않음. 저장·재시작에 같은 배치 | 명단 배치(P4-1)를 바꿈 |
| F-25 | **NPC 체력·피해·죽음**: 좀비·플레이어에게 다침, 붕대·치료제, 죽으면 시체와 소지품, 감염 | 5단계에서 앞당김 |
| F-29 | **생존 우선 결정과 수색**: 일 대신 근처 건물 보관함 수색, 물·음식·무기 챙기기, 위협 기억과 피하기, 막히면 싸우기(근접) | F-16·F-15 흡수 |
| F-30 | **거처 옮기기**: 먹을 것·물이 없거나 위험이 쌓이면 아는 빈 건물로 이사, 짐을 들고 감 | 새 티켓 |
| F-31 | **발견과 대화**: 플레이어가 다가가면 반응(숨기·경계·말 걸기), 선택지 대화, 신뢰·두려움·관계 점수 | F-20 앞부분 |
| F-32 | **포섭과 적대**: 포섭 수락 점수(성격이 크게, FD-10), 포섭된 NPC의 거처, 대화가 틀어지거나 포악한 성격이면 공격, 공격받으면 기억하고 반격·도주 | F-20 흡수 |
| F-20 | 포섭된 NPC에게 명령(일해 줘·따라와·멈춰) | 그대로, F-32 뒤 |

**진행 (2026-11-24)**: F-28 구현됨(브랜치 `f28-lone-homes`): 생성 맵이 있는 월드에서 명단 NPC는 월드 시드로 고른 생성 집에 한 명씩 살고 출근하지 않는다. 계약 docs/09 §17.13, 임시 가정·측정 docs/15 §24, 메모 notes/f28-lone-npc-homes.md. F-29 구현됨(브랜치 `f29-scavenge`): 혼자 사는 NPC가 주변 건물을 수색해 집으로 가져오고, 좀비를 본 곳을 기억해 피하고, 스스로 치료하고, 몰리면 싸운다. 계약 docs/09 §17.14, 임시 가정·측정 docs/15 §25, 메모 notes/f29-npc-scavenge.md. F-30 구현됨(브랜치 `f30-relocation`): 혼자 사는 NPC가 먹을 것이 떨어지거나 집 근처 위험이 쌓이거나 집에서 크게 다치면 스스로 다른 빈 건물을 골라 짐을 싸서 이사하고, 누가 어디 사는지의 기록이 따라 바뀐다. 계약 docs/09 §17.15, 임시 가정·측정 docs/15 §26, 메모 notes/f30-npc-relocation.md.

## 사용자에게 물을 것

네 물음 모두 2026-11-23에 답을 받았다. 물음은 기록으로 남기고 답을 아래에 적는다.

1. **건물 수.** 개발 맵 건물은 8채(집 3채)다. NPC 10명이 한 건물에 한 명씩 살려면 10채 이상 필요하다. 개발 맵에 집을 더 지을지, 한 건물에 둘까지 허용할지.
2. **포섭한 NPC.** 플레이어 거점으로 와서 사는지(침대를 정해 줌), 따라다니는지.
3. **죽은 NPC.** 소지품을 떨어뜨리는 것 말고, F-25 계획대로 좀비가 될 수 있는지.
4. **일하기.** 혼자 사는 동안에는 일이 없고 수색만 한다는 해석이 맞는지.

### 답 (2026-11-23, 사용자 말 그대로)

1. **건물 수** — "맵에 크기를 광활하게 해야해 집이 엄청 많아야해 프로젝트 좀보이드 처럼"
   → 개발 맵에 집을 더 짓거나 한 건물에 둘을 넣지 않는다. 맵을 넓히고 집을 아주 많이 만든다. 티켓 F-33(위 표)이고 F-28보다 먼저 한다. 좀보이드처럼은 규모와 느낌만이다: 배치는 새로 만든 것이고 그 게임의 맵·지명·배치를 베끼지 않는다.
2. **포섭한 NPC** — "포섭에서 같이 살고 플레이어가 동행요청하면 같이 돌아다니고"
   → 포섭된 NPC는 플레이어 거점에서 같이 산다. 플레이어가 동행을 요청하면 같이 돌아다닌다(F-32 거처, F-20 "따라와").
3. **죽은 NPC가 좀비가 되는지** — "그렇게 해"
   → 된다. F-25 계획 그대로다.
4. **일하기** — "일 할수도 있고 자유롭게"
   → 일을 강제하지 않는다. 일할지는 NPC가 스스로 정한다(성격·기분·욕구). 혼자 살 때도 포섭된 뒤에도 같다. 그래서 F-19(기분대로 일하기)는 포섭된 NPC만이 아니라 **모든 NPC**에 적용한다. 위 "지금과 달라지는 것" 표의 "일은 포섭된 뒤에만(F-20)"과 "F-19는 … 포섭된 NPC에만 쓴다"는 이 답으로 바뀐다: 수색이 기본이지만 일도 고를 수 있는 행동이다.
