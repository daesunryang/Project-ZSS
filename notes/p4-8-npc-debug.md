# P4-8 NPC AI debug overlay

## 2026-11-19

사용자 지시:

- "지금부터 쭉 작업을 진행하고 마지막에 수치랑 규칙 조정을 하자"
- "필요한 작업있으면 codex 사용량을 좀 더 늘려서 활용해"

현재 결정:

- 출하·전용 서버의 NPC 디버그는 기본 꺼짐이다. 켜도 허용된 `player_key`만 한 NPC를 구독하며 다른 접속자에게는 비공개 값이 가지 않는다.
- 꺼짐, 권한 없음, 관심 범위/메모리 밖에서는 `NpcDebugQuery`를 호출하지 않는다. 구독 샘플은 PROVISIONAL 2Hz다.
- 패널 키는 F4로 정했다. 음식 F와 셀 경계 F3 및 기존 설정 키와 겹치지 않으며 설정 검증에 포함한다.
- 클라이언트 대상 선택은 화면 중앙 반경 160px, 최대 50m의 공개 이름표 중 중앙에 가장 가까운 하나다.
- 후보와 기억은 각각 최대 5개, 경로선은 바닥 위 0.08m에 주황 `(1.0, 0.35, 0.1, 1.0)`로 그린다.
- 재현 식별자의 seed/state와 결정 시각은 문자열 정수와 정수 µs를 쓴다. Godot 4.7.2 JSON의 0.1 미만 고정밀 float 정밀도에 의존하지 않는다.
- 위 수치·규칙은 `docs/15` P4-241~P4-270에 PROVISIONAL로 기록했고 Phase 4 마지막에 실제 창·측정 결과와 함께 조정한다.
