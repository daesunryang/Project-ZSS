# fix-build-aim-hud 작업 메모

브랜치 `fix-build-aim-hud`, 기준 `5f25267`. 실제 창 첫 점검의 건축 프리뷰 조준과 왼쪽 HUD 폭을 고치고, TT-001 수정 뒤 PERF-2 ENet 트래픽을 다시 잰 작업이다.

## 2026-11-19

사용자 원문: "일단 작업 계속 해"

### 정한 것

- 화면 중앙 광선의 바닥 교점이 4m 배치 사거리 밖이면 같은 방향에서 사거리 안의 가장 가까운 그리드 슬롯을 고른다.
- 본인이 선 타일과 그 타일의 네 변은 프리뷰 후보에서 제외한다. 이 계산은 클라이언트 미리보기만 바꾸고 서버 판정과 수치는 바꾸지 않는다.
- 왼쪽 HUD 폭은 `ClientPresentationSettings.hud_left_column_width_px` 기본 420px로 두고 생존·소지품·거래 라벨을 단어 단위로 줄바꿈한다. 1280px 기준 왼쪽 패널 오른쪽 끝 428px, 오른쪽 패널 왼쪽 시작 612px라 둘 사이에 184px가 남는다.
- TT-001 수정 뒤 PERF-2 측정은 이전과 같은 고정 장면과 180틱 구간으로 한 번 실행했다. 새 표는 docs/15 §16.2에 두고 옛 표는 대역폭 버그가 있던 측정으로 표시해 남긴다.
- 새 측정에서도 FASTLZ가 서버 비용이 가장 낮고 NONE보다 wire를 크게 줄였다. wire 최소는 구간별로 ZSTD/ZLIB였지만 localhost 단일 실행만으로 기본값을 바꾸지 않는다.

### 검사와 남은 확인

- 테스트 본문은 `build_presentation` 12개, `client_presentation` 19개, `structure_view` 1개, PERF-2 측정 1개가 모두 통과했다.
- 샌드박스가 `user://logs`와 Windows 인증서 저장소를 막아 네 명령 모두 엔진 오류를 출력하고 종료 코드 1이 됐다. 정식 통과로 세지 않는다.
- 실제 창 캡처와 전체 `tools/check.sh`는 실행하지 못했다. 조정자가 샌드박스 밖에서 1280×720 건축 모드와 HUD를 다시 확인해야 한다.
