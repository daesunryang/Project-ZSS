# F-9 플레이어 기술 레벨 (브랜치 f9-skills)

- 2026-11-23 사용자 결정(계획서 FD-3·FD-8 원문): "60~200회로 하되 재료 구하면 수리 가능 / 수리 레벨 높으면 재료 감소", "10레벨, 최대 50% 감소", 해석 "레벨마다 재료 약 5.5% 감소(10레벨에서 50%), 소수점은 올림".
- 2026-11-23 구현 결정(임시, docs/15 §19 F9-001~F9-007):
  - 기술은 `SkillSettings.skill_ids`에 id만 더하면 늘어난다. 지금 `building`, `repair`. 모든 기술이 같은 경험치 곡선.
  - 감소식은 정수로: `ceil(base × (900 − (레벨−1)×50) / 900)`, 최소 1.
  - 저장은 플레이어 파일의 `systems.skills` 조각(schema 1). PlayerState 형식은 그대로(F-3 병합 충돌 줄이려고).
  - 복제는 새 모듈 SkillNet(owner 전용, 서버→클라이언트만). PROTOCOL_VERSION 18 → 19. F-3도 올리면 병합 때 한쪽만 남긴다(AGENTS.md §12).
  - 건축 경험치는 작업을 끝낸 사람(진행도 1이 된 틱의 작업자 전원)에게, 비용 감소는 놓은 사람 레벨로.
  - 새 캐릭터는 1레벨부터.
